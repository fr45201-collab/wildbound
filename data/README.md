# Data Directory

Static design databases, definitions, and gameplay schemas for Wildbound.

## Organization

- `items/` - Consumables, equipment, craftables, and materials definitions.
- `enemies/` - Enemy stat blocks, loot tables, spawn rules, and combat parameters.
- `quests/` - Quest graphs, objectives, rewards, and dialogue progression chains.

Data definitions are serialized in Lua table format or JSON for rapid iteration and hot-reloading.
