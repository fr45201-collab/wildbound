# Assets Directory

This directory houses all raw and processed game assets for Wildbound.

## Organization

- `characters/` - Character spritesheets, portraits, and animations.
- `environment/` - Background layers, props, biome features, and nature elements.
- `tilesets/` - Autotiles, rule tiles, and base terrain sets (16x16 / 32x32).
- `costumes/` - Equipment and cosmetic overlays for paperdoll character rendering.
- `weapons/` - Weapon sprites and attack motion trails.
- `items/` - Inventory item icons, ground drops, and resource objects.
- `ui/` - HUD elements, nine-slice frames, dialogue boxes, cursors, and icons.
- `audio/` - BGM tracks, atmospheric loops, and SFX samples (OGG/WAV).
- `fonts/` - Pixel fonts and UI typography.
- `manifests/` - JSON/Lua asset manifests for automated loading and texture atlases.

Refer to `docs/ASSET_PIPELINE.md` for technical specifications, format standards, and import guidelines.
