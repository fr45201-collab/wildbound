# Maps Directory

Tiled Map Editor (`.tmx` / `.json`) map files and export data.

## Organization

- `forest/` - Overworld forest regions, clearings, and wilderness biomes.
- `village/` - Hub areas, settlements, buildings, and NPC zones.
- `caves/` - Dungeon chambers, underground caverns, and mining shafts.

Maps are authored using orthogonal orientation with standard tile grids. Layering conventions (Ground, Detail, Walls, Collision, Trigger, Objects, Above) must be followed.
