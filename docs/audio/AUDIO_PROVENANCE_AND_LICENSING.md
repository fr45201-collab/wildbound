# WILDBOUND — AUDIO PROVENANCE & LICENSING DECLARATION

## 1. Provenance Statement

All audio assets created in Phase 18 for the Wildbound project are 100% original, procedurally synthesized compositions produced mathematically using Python code.

* **Zero Copyrighted Recordings**: No commercial music recordings, pre-recorded sample packs, royalty-free audio libraries (e.g. Freesound, Epidemic Sound), or rips from existing video games were used or referenced.
* **Deterministic Synthesis**: Every single `.wav` file was computed directly from mathematical equations:
  * Trigonometric functions: $\sin(\omega t)$
  * Piecewise linear/exponential envelope curves
  * Pseudo-random uniform noise distributions
  * Algorithmic digital filters and delay buffers
* **Ownership**: Wildbound holds full, unrestricted intellectual property rights over all audio waveforms, generator algorithms, and metadata files.
