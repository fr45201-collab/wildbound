## 3. Reusable Button Style Collection

Located in `assets/ui/buttons/`. Every button archetype has 6 complete interactive states: `normal`, `hover`, `pressed`, `disabled`, `selected`, `focused`.

| Style Category | Base Coloration | Associated Actions |
|---|---|---|
| `btn_primary_*` | Tempered slate blue with gold border | Navigation, menu selection, character tabs |
| `btn_confirm_*` | Deep forest moss green with emerald border | Play game, equip armor, craft, confirm selection |
| `btn_destructive_*` | Crimson bloodiron with ruby border | Quit game, discard item, cancel dialog, reset |
| `btn_tab_*` | Midnight slate with highlight active border | Horizontal category tabs (Inventory, Wardrobe) |
