# Player Input Mapping & Key Bindings

## 1. Gameplay Locomotion Controls

| Key | Alternate Key | Action | Description |
| :--- | :--- | :--- | :--- |
| `W` | `Up Arrow` | Move North | Walks or runs upwards |
| `S` | `Down Arrow` | Move South | Walks or runs downwards |
| `A` | `Left Arrow` | Move West | Walks or runs to the left |
| `D` | `Right Arrow` | Move East | Walks or runs to the right |
| `Left Shift` | `Right Shift` | Sprint / Run | Multiplies movement speed from 100 to 165 px/s |
| `Escape` | — | Pause / Quit | Closes active UI or exits the game engine |

---

## 2. Developer & Diagnostic Hotkeys

| Key | Subsystem | Action | Description |
| :--- | :--- | :--- | :--- |
| `F1` | DevUI | Toggle Developer UI | Toggles Dear ImGui developer overlay |
| `F2` | Camera | Toggle Camera Mode | Cycles between Follow mode and Free camera mode |
| `F3` | Debug Overlay | Collision Bounds Overlay | Visualizes character feet collision boxes and environment AABBs |
| `F4` | Debug Overlay | Entity Origin Marker | Toggles crosshair at the player's ground anchor point |
| `F5` | Debug Overlay | Animation HUD | Displays live movement state, current clip, frame index, and facing |
| `R` | Gameplay / Debug | Reset to Spawn | Instantly teleports player to map's `player_spawn` marker |
